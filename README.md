# Fit You — 브랜드 사이즈·코디 추천 위젯 (무신사)

무신사 **아우터** 상품 페이지의 "구매하기" 버튼 아래에 브랜드 기반 사이즈 추천 위젯을 띄우는 Chrome 확장 프로그램(Manifest V3)입니다.
사이즈 추천과 함께 코디 세트, 비슷한 상품도 보여줍니다.

## 주요 기능

- **사이즈 추천**: 브랜드·상품별 리뷰 여론을 −2(작아요) ~ +2(커요) 점수로 계산하고, 평소 입는 사이즈 또는 구매 이력을 기준으로 추천 사이즈를 제시합니다.
- **실측 사이즈표 비교**: 상품 페이지의 실측표를 읽어 cm 단위로 비교 근거를 보여줍니다. 번호 사이즈(1~4)는 상품별 실측표 기반 매핑을 우선하고, 구분이 안 되면 기존 매핑을 쓰되 근사값임을 표시합니다.
- **실제 판매 사이즈 우선**: `F`/`FREE` 같은 사이즈는 원문 그대로 표시하고, 계산된 사이즈가 판매 목록에 없으면 다른 사이즈로 대체하지 않고 경고와 판매 사이즈 목록을 보여줍니다.
- **평소 입는 사이즈 변경**: 드롭다운을 바꾸면 즉시 해당 기준으로 다시 계산합니다.
- **코디·비슷한 상품 추천**: 무신사 상품 상세 API 기반으로 코디 세트와 비슷한 상품을 위젯 안에 표시합니다.
- **최근 본 상품**: 확장 아이콘 팝업에서 최근 본 상품 목록을 확인합니다.

## 설치 (개발자 모드)

1. 이 저장소를 내려받습니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 우측 상단 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 폴더를 선택합니다.
5. 무신사 아우터 상품 페이지(`https://www.musinsa.com/products/...`)에 접속하면 위젯이 나타납니다.

## 파일 구성

| 파일 | 역할 |
|------|------|
| `manifest.json` | 확장 프로그램 설정 (권한, 콘텐츠 스크립트 등록) |
| `content.js` | 상품 페이지에 주입되어 위젯 삽입·사이즈 계산·렌더링 |
| `background.js` | 서비스 워커. 모델 데이터 로드와 무신사 API 요청 중계 |
| `outfit-recommendations.js` | 코디·비슷한 상품 추천 |
| `widget.html.js` / `style.css` | 위젯 마크업 / 스타일 |
| `popup.html` / `popup.js` / `popup.css` | 최근 본 상품 팝업 |
| `model/` | 브랜드 사이즈 모델(`model.json`)과 상품 조회표(`product_lookup.json`) |
| `tests/` | 스모크 테스트 |

## 테스트

```
node tests/red-team.smoke.test.js
```

## 권한

- `storage`: 최근 본 상품, 평소 입는 사이즈 등 설정 저장
- `musinsa.com` 계열 호스트: 상품·실측표·리뷰 데이터 조회

## 유의사항

- 무신사 공식 서비스가 아니며, 추천 결과는 참고용입니다.
- 무신사 페이지 구조가 바뀌면 동작이 달라질 수 있습니다.
